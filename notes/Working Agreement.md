# Working Agreement

- nate owns the game. The build spec (https://claude.ai/artifact/BTWzdUABUjnZoUMjq2dfoC) is the source of truth; nate's docs are never edited. Spec changes go in Decisions.md.
- Build the spec's milestones in order, one at a time. Report at each milestone with what to test in Studio.
- nate is often away from his PC. Write as much as possible in code; anything only Studio can prove (feel, performance, art, sound) goes on the Studio test list in Tasks.md.
- Quality first: lint clean, tests pass, place builds before anything is called done.
- Decisions go straight into chat with the context for each, so nate never has to dig through docs.
- Never download assets, spend money or publish without nate's OK. Original characters only; no real people, brands or memes.
- No free text anywhere (names, maps, signs are presets). Map sharing is piece-based.
- Physics stays simple: rigid-body cars, light ragdoll. Phone first.
- Every decision is weighed by reach (players, retention, virality) and revenue, within the design pillars.
